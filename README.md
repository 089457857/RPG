# 屁眼王國大冒險：架設到 Render 的教學

2D 像素橫向捲軸連線打怪遊戲，有自己的網址和帳號系統，跟牛牛完全分開。

流程和當初架牛牛幾乎一樣，但多了一步：**把牛牛的資料庫網址貼過來**（第三步會說明原因）。

---

## 第一步：建立新的 GitHub repository

1. 到 https://github.com ，按右上角「＋」→「New repository」。
2. Repository name 填 `pyan-rpg`，選 **Private**，其他選項都不要勾，按「Create repository」。
3. 點「uploading an existing file」，把這個資料夾裡的 **6 個檔案**一起拖進去：
   - `index.html`
   - `server.js`
   - `rpg.js`
   - `rpg-data.js`
   - `package.json`
   - `render.yaml`
4. 按「Commit changes」。

## 第二步：在 Render 建立 Blueprint

1. 到 Render，按「New」→「Blueprint」，選 `pyan-rpg` 這個 repository，按「Connect」。
2. **Blueprint Name** 填 `pyan-rpg`。
3. 往下捲會看到一欄 **DATABASE_URL**，先不要按 Deploy，照第三步取得網址。

## 第三步：填 DATABASE_URL（用牛牛的資料庫）

Render 免費方案**一個帳號只能有一個免費資料庫**，牛牛已經用掉了，所以 RPG 要借用同一個資料庫。兩邊的資料會分開存，不會互相影響（RPG 的資料存在 `pyan-rpg` 這一格，牛牛的存在另一格）。

1. 另開一個分頁回到 Render 主畫面，點進牛牛的資料庫 `niuniu-db`。
2. 往下找到「Connections」裡的 **Internal Database URL**，按複製。
3. 回到 Blueprint 頁面，把網址貼進 **DATABASE_URL**。
4. 按「**Deploy Blueprint**」，等 3～5 分鐘。

> 如果 DATABASE_URL 留空，遊戲還是能玩，但伺服器每次重啟或休眠後，帳號和角色都會消失。

## 第四步：開始玩

1. 點進 `pyan-rpg` 服務，打開上方的網址，例如 `https://pyan-rpg-xxxx.onrender.com`。
2. 第一次進來先註冊，暱稱和密碼跟牛牛是**分開**的。
3. 選職業就能開始；把網址傳給朋友，大家註冊後就會在同一張地圖相遇。

## 玩法重點

- **一起打比較划算**：怪物被多人一起打時，每個有出手的人都分得到經驗。
- **聊天**：按 Enter 開始打字，訊息會出現在角色頭上和聊天欄。
- **轉職**：15、30、45、60 級各轉職一次（共四轉）。在晨露村找轉職教官接「轉職試煉」，到專屬的試煉之地一個人打倒試煉官就能轉職（一轉 1 招～四轉 4 招，預警長、傷害低，失敗可重試、不扣經驗）。滿等 80 級。65 級解鎖寵物（青龍、玄武、白虎、朱雀四選一）。
- **地圖**：蘑菇森林 → 冰雪山谷 → 熔岩深淵 → 暗黑神殿 → 天空聖域 → 虛空裂隙，傳送門沒有等級限制，只標示建議等級。
- **職業**：戰士、法師、刺客、射手、格鬥家、機械戰士、惡魔、天使，共 8 種，每個職業 7 個技能，彼此不重複。天使能治療、祝福、保護、復活隊友。
- **坐騎**：Lv 10 起按 F（手機按「坐騎」）上下坐騎，騎乘中無法攻擊，但受到的傷害會減少 25%～40%（越高級的坐騎減越多）。共 7 種：棕色小馬（送的）、雪原狼、黃金獅子、重型機車（晨露村商店購買），黑龍、筋斗雲、虛空戰獸（黑龍王／天穹泰坦／虛空之主掉落）。每種速度、跳躍高度不同，高級坐騎按住跳躍可以滑翔。在「角色 → 坐騎」切換。
- **傳送門**：每張地圖左邊的傳送門會回到前一張地圖。
- **技能配置**：每一轉 3 個技能（每個職業共 15 個＋普攻），按「技能」挑 6 個放進 X C V B N M。
- **手機**：操控改為輪盤搖桿。橫向自動進入全螢幕版面：狀態列縮成一小條，按 ☰ 打開選單；技能按鈕直接顯示冷卻秒數與 MP 不足。直向維持「上面遊戲、下面按鍵」。用 Safari／Chrome 開啟後「加入主畫面」，從桌面圖示進入就沒有網址列。電腦版不受影響，可以按「全螢幕」。
- **地圖格局**：6 張地圖的平台、繩子配置都不一樣（樓梯、高塔、長橋、浮島、鋸齒）。
- **Boss 回血**：玩家都躲在 Boss 打不到的地方超過 4 秒，Boss 會每秒回復 3% HP。
- **升級曲線**：每級所需經驗 = 12 × 等級^1.8，後期比舊版難約 4 倍。
- **PVP**：按「PVP」開啟面板。決鬥：邀請同地圖的玩家 1 對 1，傳送到決鬥場，限時 3 分鐘，輸了不掉東西。競技場：所有人混戰，打倒 +10 分（對手低 15 級以上只 +2）、被打倒 -3 分，場內復活，有積分排行榜。PVP 的血量與傷害由伺服器判定，傷害打折並修正等級差距。
- **多角色**：每個帳號最多 6 個角色，登入後在「選擇角色」畫面切換；遊戲中按「換角」回到角色列表。
- **能力值**：每升 1 級得 3 點。每個職業有主屬性（戰士／格鬥家：力量，法師／天使：智慧，刺客／射手：敏捷，機械戰士：力量＋智慧，惡魔：力量＋體質），主屬性每點攻擊 +1.3。力量加擊退、體質加 HP／防禦／無敵時間、智慧加技能傷害／冷卻縮短／治療、敏捷加爆擊／爆傷／移速。每項點越多效率越低（100 點後 70%、200 點後 40%）。重置 20,000 金幣；改版時每個既有角色補償 20,000 金幣。
- **虛空裂隙**：第 6 張地圖，怪物 Lv 86～100，必須組隊；怪物會隨機掉落各職業的傳說專屬武器，Boss 虛空之主掉落率最高。
- **Boss 招式**：6 隻 Boss 各有 3 招專屬招式（共 18 種，不重複），出招前都有紅色預警並顯示躲法。巨菇王：重壓／滾動巨菇／蘑菇跳壓；冰霜巨人：冰錐陣／寒霜吐息（減速）／冰環爆發；炎魔王：隕石雨／熔岩漩渦／火海輪替；黑龍王：龍息／龍爪突襲／甩尾；天穹泰坦：天崩地裂／天罰橫掃（站在地上別跳）／神之審判；虛空之主：混沌追蹤／虛空環繞／虛空分裂。血量低於 30% 會暴怒。
- **排行榜**：「角色」按鈕裡可以看等級排行和線上人數。
- **存檔**：角色存在伺服器，換手機或電腦登入都能接著玩。

## 免費方案提醒

- **休眠**：15 分鐘沒人連線就會休眠，下次打開要等約 1 分鐘。
- **共用時數**：牛牛和 RPG 是兩個服務，共用每個月 750 小時的免費額度。只要不是兩個都 24 小時有人在玩，通常夠用。
- **資料庫到期**：免費資料庫建立 30 天後會到期，牛牛和 RPG 的資料會一起受影響。要長期經營，建議把資料庫升級成付費方案。

## 之後要修改遊戲

在 GitHub 的 `pyan-rpg` 上修改檔案並 Commit，Render 會自動重新部署。


## 資料備份與掛機斷線

- 資料備份在「哪有小孩天天輸」的管理後台（兩個遊戲共用資料庫，一個備份檔就包含兩邊的資料）。還原後本遊戲會在 15 秒內自動重新載入。
- 5 分鐘沒有任何操作會自動斷線，節省 Render 的免費時數；點「重新連線」就能繼續。

## GM 測試帳號

1. 先在遊戲裡正常註冊一個帳號（例如「GM測試」）。
2. 在 GitHub 的 RPG 專案新增一個檔案 `gm.txt`，內容寫這個帳號的暱稱（多個帳號一行一個），存檔後 Render 會自動重新部署。也可以改用 Render 的環境變數 `RPG_GM`。
3. 用這個帳號登入、建立任一角色後，下方會多出「GM」按鈕：可以自由選職業、轉數、等級（1～80）和寵物，按「套用」立刻變身，裝備自動給到該等級最好的（Lv 80 給傳說武器）。
4. GM 角色不會出現在等級排行榜和競技場排行榜，名字後面會顯示［GM］讓其他玩家知道。


## Boss 危險區

每隻 Boss 腳下會畫出紅色的危險區（範圍依牠最遠的招式射程而定）。站在危險區外，或爬到 Boss 上方的高處平台攻擊，Boss 不會受傷，頭上會顯示「免疫」；從地面跳起來攻擊仍然算數。
